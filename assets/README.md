# 사진 출처

현재 발표에는 새로 고른 사진 6장을 사용합니다. 화면별 배치와 원문 링크는 [사진 가이드](../사진_교체_가이드.md), APA 7판 서지정보는 [참고문헌](../참고문헌_APA.md)의 사진 항목에서 확인할 수 있습니다.

파일명: 01-control-room.jpg, 03-remote.jpg, 04-camera.jpg, 09-television.jpg, 14-mobile.jpg, 16-editor.jpg.

모두 Unsplash에서 무료 사용 가능한 사진으로 확인했습니다. [Unsplash License](https://unsplash.com/license)가 적용됩니다. 사진 원본을 재판매하거나 사진 서비스로 묶어 배포하기 위한 자료가 아닙니다. 피사체의 상표와 인물은 발표를 보증하지 않습니다.

기존 architecture.jpg와 production.jpg는 이전 버전 복원용으로 보관하며, 현재 화면에는 표시하지 않습니다. 이전 이미지 링크는 Git 이력에 남아 있습니다.
